# E-commerce Data Analysis with Python

## About the Project

I built this project to practise data analysis using Python and learn how to work with a real-world style dataset. I explored customer purchasing patterns, product categories and transaction amounts to understand what the data could tell me.

## Dataset

The dataset contains 55,000 records with details about purchase dates, customer demographics, product categories, payment methods, discounts and transaction amounts.

## What I Did

- Cleaned the data and checked for missing values and duplicates
- Explored sales across different product categories and purchase methods
- Compared transaction amounts across gender, age groups and locations
- Investigated records with negative Net Amount values
- Created charts to make the results easier to understand

## Visualizations

I created five charts to explore different parts of the dataset:

- **Bar Chart:** Compared total Net Amount across product categories
- **Pie Chart:** Showed how frequently different purchase methods were used
- **Scatter Plot:** Explored the relationship between Gross Amount and Net Amount
- **Box Plot:** Compared transaction amounts across age groups
- **Correlation Heatmap:** Looked at relationships between numerical transaction amounts

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files

- `project.ipynb` — Data cleaning and exploratory data analysis
- `visualization.ipynb` — Charts and visual analysis
- `cleaned_data.csv` — Cleaned dataset used for the visualizations

## What I Learned

While working on this project, I got hands-on practice with data cleaning, exploratory data analysis and creating charts in Python. I also learned the importance of investigating unusual values instead of immediately assuming they are errors.

## How to Run

1. Download or clone this repository.
2. Install Python and Jupyter Notebook, along with Pandas, Matplotlib and Seaborn.
3. Open `project.ipynb` to explore the data cleaning and analysis.
4. Open `visualization.ipynb` to view the charts.

Keep `cleaned_data.csv` in the same project folder as `visualization.ipynb` so the notebook can load the data correctly.
